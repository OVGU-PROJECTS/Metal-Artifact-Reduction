
# Conditional invertible neural network

The conditional invertible neural network (cINN) operates in the latent space of a previously trained conditional VAE. Its purpose is to model the latent variability of corrupted CT patches that is compatible with a fixed MAR prediction and metal mask.

The cVAE is kept frozen during cINN training. For each patch, the corrupted input `x`, MAR prediction `p`, and metal mask `m` are loaded. The cVAE encoder receives `[x, p, m]` while the cINN is conditioned on `[p, m]`.

A latent sample `z` is drawn from the cVAE posterior and passed through the cINN. The forward transformation maps the cVAE latent representation to an approximately standard-normal latent variable `v`

The reverse transformation maps a sampled latent variable back into the cVAE latent space.

The resulting latent representation can then be decoded by the frozen cVAE under the same condition to generate alternative corrupted-image realizations compatible with the fixed MAR prediction.

The conditioning maps are processed by a convolutional embedder before being supplied to the conditional flow. Each flow block consists of ActNorm, an invertible LeakyReLU activation, a conditional affine coupling transformation, and a channel shuffle. The corresponding log-determinants are accumulated for maximum-likelihood training.

The cINN is optimized using the negative log-likelihood objective
`0.5 * sum(v^2) - logdet`.

## Pairing with the conditional VAE

Each cINN must be paired with the conditional VAE trained for the same MAR method. The MAR prediction used by the dataset and the cVAE checkpoint therefore have to correspond to the same condition.

For example, for DuDoNet:

```yaml
vae_checkpoint: results/runs/cvae/cvae_dudonet/checkpoints/best.pt
pred_name: dudonet
```
Use the corresponding pair for `cnnmar` or `pconv`. A DuDoNet cINN should therefore not be trained using a CNN-MAR or PConv-MAR cVAE checkpoint.

## Training

Example training command:

```bash

GPU1=$(gpurequest)
GPU2=$(gpurequest)

CUDA_VISIBLE_DEVICES="$GPU1,$GPU2" python -u -m MAR_Inv.cinn.trainer_new \
  --config "configs/cinn.yaml" \
  --devices 0,1 \
  --out_dir "results/runs/cinn/cinn_dudonet_new"
```

The trainer saves the latest checkpoint, the checkpoint with the lowest validation loss, and periodic checkpoints according to the configured saving interval.

## Sampling

After training, new realizations can be generated by sampling

`v ~ N(0, I)`

and applying the inverse cINN transformation under the desired condition:

`v -> cINN inverse -> z -> cVAE decoder -> sampled corrupted patch`

The same MAR prediction and metal mask are used throughout the inverse transformation and cVAE decoding.
